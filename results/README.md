# Results

This folder contains selected outputs from the Olist SQL analysis.

## Monthly on-time delivery rate

The chart shows the monthly share of delivered orders delivered on or before the estimated delivery date, grouped by purchase month. It is based on [`07_delivery_performance_by_purchase_month.sql`](../sql/04_business_analysis/07_delivery_performance_by_purchase_month.sql). The first month has only one delivered order, so interpret its 0% rate cautiously.
