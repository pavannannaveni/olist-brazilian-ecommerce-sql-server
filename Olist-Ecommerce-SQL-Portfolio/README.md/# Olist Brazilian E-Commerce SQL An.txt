# Olist Brazilian E-Commerce SQL Analysis

A SQL Server portfolio project analyzing the public [Brazilian E-Commerce dataset by Olist](https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce).

## Project goal

Explore order activity, sales, payments, delivery, products, sellers, and customer reviews using SQL Server.

## Current analysis

`sql/04_monthly_revenue_by_purchase_month.sql` summarizes delivered orders by purchase month. It calculates merchandise value and freight from order items, and recorded payment value from payment records. Each table is aggregated by order before joining to avoid multiplying amounts.

## Data quality notes

- The imported columns in the core order, item, payment, and review tables are stored as `varchar`.
- The analysis uses `TRY_CONVERT` when reading date and amount values.
- SQL Server has no primary or foreign key constraints defined on the imported tables.
- One delivered order in September 2016 has no matching payment row. The analysis reports this as a missing payment rather than treating it as a zero payment.

## Running the analysis

1. Load the Olist dataset into SQL Server.
2. Use a database named `Ecommerce` with the expected table names.
3. Open the SQL script in SQL Server Management Studio and run it.

The dataset itself is not included in this repository.
